# OUR CAFÉ ☕

두 사람이 함께 카페 창업을 준비하고 운영하기 위한 Android 앱.

## 목표
- 한눈에 보는 창업 대시보드
- 공동 할 일과 단계별 창업 로드맵
- 작성자/수정시간이 기록되는 공동 메모
- 예산, 지출, 매물 및 견적 비교
- 인테리어 사진 보드, 메뉴 원가표, 사업계획서

## 기술 계획
- Kotlin + Jetpack Compose (Android)
- Firebase Authentication + Cloud Firestore (공동 동기화)
- Firebase Storage (사진 첨부, 사용량/요금 확인)
- Room (오프라인 캐시, 후속 단계)
- GitHub Actions (APK 빌드)

## 구현 순서
1. 실행 가능한 Android 앱 골격 + 홈 화면 + GitHub Actions 빌드
2. 로드맵, 할 일, 메모의 로컬 CRUD
3. Firebase 로그인 및 두 사람 전용 워크스페이스
4. 실시간 동기화, 보안 규칙, 동시 수정 처리
5. 예산/지출/매물/사진 보드
6. 사업계획서와 PDF 내보내기, 운영 기능

## 안전 원칙
- 저장소는 공개 상태이므로 API 비밀키, 서비스 계정 JSON, 개인 메모, 재무 데이터, 서명키를 커밋하지 않습니다.
- Firestore 보안 규칙으로 워크스페이스 구성원만 데이터를 읽고 수정하도록 제한합니다.
- 실제 공동 기록은 GitHub 저장소가 아니라 접근 통제된 데이터베이스에 저장합니다.

> 현재 단계: 기획 문서 초기화. Android 코드 및 APK 빌드는 아직 구현되지 않았습니다.
